# Homebrew tap

```sh
brew install --cask diegobruegger-prog/tap/cablepeek
```

[CablePeek](https://github.com/diegobruegger-prog/cablepeek) shows the USB-C link speed, or the charging power, at the screen edge next to the port when you plug something in.

The app updates itself, so `brew upgrade` is only needed if you turned automatic updates off.
